## Происхождение данных ВМ

Ранняя копия содержит 4 553 распакованных файла сырых замеров, 38 сводок и 31 файл в каталоге графиков. Их содержимое совпадает с файлами в публикационном дереве. Макет исходных каталогов и имена файлов сохранены.

Полная копия VirtualBox от 19 октября 2026 года дополняет распакованный набор. Из неё восстановлены **1 459 сжатых трасс и журналов** в исходные каталоги прогонов и **9 архивов** в `archive/`. Они доступны локально в подготовленном каталоге. После клонирования с GitHub доступны обычные CSV, метаданные, сводки, изображения и манифесты. Для повторной атрибуции или пересчёта по всем запросам понадобятся полные трассы и журналы соответствующей серии.

## Полный локальный набор

В подготовленном каталоге также доступны полные данные нативных серий. Добавлены ещё 15 архивов, 3 667 сжатых файлов и двоичная трасса прерванного прогона. Крупные файлы используют жёсткие ссылки на исходные локальные файлы, чтобы избежать второй копии на диске. Сырые измерения сохраняются без редактирования.

В разделах `results/vm/` и `results/native/` локальные `raw/` и `trace-archives/` ведут к соответствующим прогонам и архивам. В GitHub те же прогоны доступны через ссылки по датам в README разделов. Сводки в разделах копируются без изменений из `results/summary/`. После добавления новых таблиц или прогонов каталог можно обновить:

```bash
python3 scripts/catalog-results.py
```

## Проверка полного архива

Если архив лежит в `archive/` и его файлы разложены по исходным путям, из корня репозитория можно проверить контрольные суммы. Пример для основной HTTP-серии ВМ:

```bash
sha256sum -c results/trace-manifests/stage2-load-20261018-111123.sha256
```

Фазы HTTP и тиков обозначены `pre` (контроль), `merge` (слияние) и `steady` (устойчивый режим). Для тиков поля и ограничения измерения описаны в [README нагрузок](../workloads/ticksrv/README.md) и [Л14](limitations.md#л14-границы-измерения-тика-в-luanti-и-godot).
